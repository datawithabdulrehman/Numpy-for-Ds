# 🔢 NumPy for Data Science (Numpy-for-Ds)

Welcome to my NumPy repository! This project contains a comprehensive, step-by-step implementation of multi-dimensional arrays, vector computations, numerical operations, and practice exercises using the Python **NumPy** library. NumPy forms the essential foundation for numerical processing in Pandas and Machine Learning frameworks.

## 🛠️ Tech Stack & Prerequisites
* **Python 3.x**
* **NumPy** (Numerical Python)
* **Jupyter Notebook / JupyterLab**

---

## 📂 Repository Structure & Notebooks

Here is a structural breakdown of the concepts and practice modules covered in this repository:

### 1. 🧮 Array Basics & Foundations
* **`Arrays.ipynb`**: Introduction to creating 1D, 2D, and multi-dimensional arrays using lists, `np.arange()`, `np.zeros()`, `np.ones()`, `np.linspace()`, and generating random numbers with `np.random`.

### 2. 🎯 Indexing, Slicing & Selection
* **`array_indexing.ipynb`**: Deep dive into extracting single elements, multidimensional array slicing, broadcasting values, and conditional boolean indexing (filtering arrays based on conditions).

### 3. ⚡ Array Math & Vectorized Operations
* **`array_operations.ipynb`**: Performing lightning-fast element-wise arithmetic (addition, multiplication), universal array functions (`np.sin`, `np.log`, `np.max`, `np.sqrt`), and handling axis-based calculations (rows vs columns).

### 📝 Practice & Workouts
* **`exersises.ipynb`**: A comprehensive workbook containing targeted problems and challenges designed to reinforce and master core numerical array operations.

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project folder:**
   ```bash
   cd Numpy-for-Ds
   ```
3. **Install NumPy (if not already installed):**
   ```bash
   pip install numpy
   ```
4. **Launch your notebook environment:**
   ```bash
   jupyter lab
   ```
